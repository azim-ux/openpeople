# OpenPeople public showcase

Live project page: https://azim-ux.github.io/openpeople/

Interactive fictional dashboard: https://azim-ux.github.io/openpeople/demo/

The dashboard is a browser-only workflow demonstration. Its records are fictional; edits are in memory and disappear on reset or reload. It has no accounts, backend, tracking, analytics, browser storage or external runtime dependencies. The full Python + SQLite application and platform installers are available on the main branch and v0.8.2 release.

Before publication, 20 isolated browser checks passed covering the overview, directory search and filtering, sample approvals and leave submission, date validation, onboarding, reset and reload, responsive layouts, navigation links, social metadata and browser error/network checks. Five screenshots were captured.

This is the static GitHub Pages branch. Source code: https://github.com/azim-ux/openpeople/tree/main
